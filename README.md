# charactercounter
JavaScript. The tool allows users to type text into a message box and instantly see the number of characters entered. Users are notified in real time if they exceed the 200-character limit, ensuring concise inputs for messaging or form submissions.​

## Features
Real-time character counting as users type in the input area

Maximum character limit indicator with immediate feedback

Alert and color change when the limit is reached

Clean, user-friendly interface

Responsive design suitable for desktop and mobile browsers

## Technologies Used
HTML for the structure of the input field and counter

CSS for styling and responsive layout

JavaScript for dynamic count logic, limit enforcement, and interactive feedback
